Worker mode

Off by default. When you turn it on, this visible Chrome window claims Etsy searches from a backend you configure, types them into Etsy's search box, and uploads each results page as it finishes. Nothing here is hardcoded. Leave the window open and in front — the lane is headed, never headless.

Paste the publishable key or the legacy anon key. A service_role JWT or an sb_secret_ key is rejected. The key is sent as apikey, never as the bearer token.

Sign-in uses email and password against Supabase Auth. The password is not saved. The refresh token stays in this browser.

Default poll is 20 seconds. Chrome may not wake a sleeping extension faster than every 30 seconds, which is still inside the two-minute pickup budget. Realtime is a faster hint when your project publishes etsy_worker.jobs.
